# Material for the next phase — real data & real exercises

The app is a **simulator**: nothing contacts an agency, and every borrowed layer is labelled on screen
(interim boundaries → DERIVED; river thresholds → proxy; shelter capacities → blank until official).
This folder holds the requests that replace those labels with official data, plus the drill scripts.

**SEND_PACKAGE.md** is the entry point: who gets each letter, what attaches, and where each answer plugs in.
Letters 01 and 03 were updated (2026-10-07) to match the app as it exists: a tabletop *simulation* exercise
(no SMS), and a concrete ask for official barangay **boundary files** — which no public dataset carries.
