# Contact verification call sheet

**Purpose:** confirm each published number really reaches the right desk, *before* ClimateShield ever sends a dispatch SMS to it.
**Source of numbers:** official City Government of Dagupan website — `dagupan.gov.ph/contact-us` and `dagupan.gov.ph/the-city/department-heads` (both retrieved 2026-10-05). Landlines use area code **(075)**.
**Time needed:** about 45 minutes for one person.

## Call script (Tagalog / English)

> "Magandang araw po. Ako po si ____ mula sa ClimateShield-Dagupan, isang community flood-preparedness project. Gusto lang po naming i-confirm kung ito pa rin ang tamang numero ng [OFFICE] para sa emergency. Tumatanggap din po ba kayo ng SMS sa numerong ito? May iba pa po ba kayong hotline na mas mainam gamitin kapag baha?"
>
> "Good day. I'm ____ from ClimateShield-Dagupan, a community flood-preparedness project. We'd like to confirm this is still the right emergency number for [OFFICE]. Does this number also accept SMS? Is there a better hotline to use during floods?"

Ask: right office? 24/7? accepts SMS? preferred number during floods? OK to receive structured dispatch texts during drills (tagged [DRILL])?

## After calling

In the app → 🚑 Response & Dispatch → 📒 Directory:
1. Correct any number that changed; put "phone call YYYY-MM-DD" in **source**.
2. Tick **confirmed_by_call**.
3. Tick **sms_dispatch_ok** only if the office agreed to receive dispatch texts.
4. Save. Only rows with both ticks appear in "Send dispatch SMS".
